# Подключение бота к 1С — пошаговая инструкция

> Эту инструкцию нужно выполнить **на стороне 1С** (в Конфигураторе и на веб-сервере).
> После этого бот подключится к 1С автоматически — нужно будет только прописать
> адрес, логин и пароль в файле `config.py`.

---

## Зачем это нужно

Сейчас бот при оплате выдаёт **тестовые коды** (`TEST-CODE-...`).
Чтобы он выдавал **реальные коды активации из 1С**, в 1С нужно создать
«точку входа» — **HTTP-сервис**. Бот будет обращаться к ней по сети.

Схема работы:

```
Клиент оплатил  →  ЮКасса уведомила бота  →  бот спросил у 1С код
                                          →  1С вернула код
                                          →  бот отправил код клиенту
                                          →  бот сказал 1С "код выдан"
```

---

## Твоя конфигурация (определено)

- **Платформа:** 1С:Предприятие 8.3 (8.3.27.1688)
- **Конфигурация:** Управление сервисным центром, ред. 3.0 (УНФ СЦ), на поддержке
- **Режим базы:** Файловый, путь к каталогу задаётся в `.env` через `ONEC_BASE_PATH`
- **Пользователь:** учётная запись внутри 1С (задаётся в `.env` через `ONEC_USERNAME`)

Из этого следуют два важных момента:

1. **Конфигурация типовая (на поддержке).** Чтобы не снимать её с поддержки
   (это ломает обновления), HTTP-сервис добавляем через **расширение
   конфигурации** — отдельный «слой», который не трогает основную конфигурацию.
2. **База файловая.** Чтобы сервис заработал по сети, на этом компьютере нужен
   **веб-сервер** (Apache или IIS), который опубликует базу. Без него никак.

---

## Шаг 1. Создать HTTP-сервис через расширение конфигурации

1. Открой базу в режиме **Конфигуратор** (ярлык 1С → выбрать базу → кнопка
   «Конфигуратор»).
2. Меню **«Конфигурация» → «Расширения конфигурации»**.
3. В открывшемся окне нажми кнопку **«Добавить»** (зелёный плюс). Заполни:
   - **Имя:** `БотЛицензии`
   - **Префикс:** `бл_` (любой короткий, чтобы имена не пересекались)
   - **Назначение:** `Дополнение`
   - ОК.
4. Теперь в окне расширений нажми **«Открыть конфигурацию расширения»** —
   откроется дерево, как у обычной конфигурации, но почти пустое.
5. В этом дереве найди ветку **«Общие» → «HTTP-сервисы»** → ПКМ → **«Добавить»**.
6. Свойства нового сервиса:
   - **Имя:** `licenses`
   - **Корневой URL:** `licenses`
7. Внутри сервиса добавь **шаблоны URL** (ПКМ на сервисе → Добавить → Шаблон URL):

   | Имя шаблона | Шаблон (поле «Шаблон») |
   |-------------|------------------------|
   | `getcode`   | `/getcode`             |
   | `confirm`   | `/confirm`             |
   | `stock`     | `/stock`               |

8. Для каждого шаблона добавь **Метод** (ПКМ на шаблоне → Добавить → Метод):

   | Шаблон    | HTTP-метод | Имя метода обработчика |
   |-----------|-----------|------------------------|
   | `getcode` | `GET`     | `getcodeGET`           |
   | `confirm` | `POST`    | `confirmPOST`          |
   | `stock`   | `GET`     | `stockGET`             |

9. После ввода кода (Шаг 2) сохрани: **«Конфигурация» → «Обновить конфигурацию
   базы данных»** (F7).

## Шаг 2. Вставить код обработчиков

Открой **Модуль** HTTP-сервиса (ПКМ на сервисе `licenses` → «Открыть модуль»)
и вставь туда этот код. **Места, помеченные `// ⚠️ ЗАМЕНИ`, нужно
адаптировать под то, где у тебя реально хранятся коды активации**
(регистр сведений, справочник, документ — зависит от твоей конфигурации).

```bsl
// ============================================================
// HTTP-сервис licenses — выдача кодов активации боту Telegram
// ============================================================

// GET /licenses/getcode?product=...&order_id=...&quantity=...
// Возвращает: {"codes": ["CODE1", "CODE2"]}
Функция getcodeGET(Запрос)

    Продукт    = Запрос.ПараметрыЗапроса.Получить("product");
    ИдЗаказа   = Запрос.ПараметрыЗапроса.Получить("order_id");
    Количество = Число(Запрос.ПараметрыЗапроса.Получить("quantity"));

    Если Количество <= 0 Тогда
        Количество = 1;
    КонецЕсли;

    МассивКодов = Новый Массив;

    // ⚠️ ЗАМЕНИ этот блок на запрос к твоему хранилищу кодов.
    // Пример: выбрать "Количество" свободных кодов для "Продукт",
    // пометить их как зарезервированные под "ИдЗаказа" и вернуть.
    //
    // Запрос = Новый Запрос;
    // Запрос.Текст = "ВЫБРАТЬ ПЕРВЫЕ &Кол Код ИЗ РегистрСведений.КодыАктивации
    //                 ГДЕ Продукт.Наименование = &Продукт И Статус = ЗНАЧЕНИЕ(...Свободен)";
    // ... заполнить МассивКодов ...
    //
    // НИЖЕ — временная заглушка, чтобы проверить связь (удали потом):
    Для Сч = 1 По Количество Цикл
        МассивКодов.Добавить("1C-" + ИдЗаказа + "-" + Сч);
    КонецЦикла;

    Ответ = Новый Структура("codes", МассивКодов);
    Возврат ОтветJSON(Ответ, 200);

КонецФункции

// POST /licenses/confirm
// Принимает: {"order_id": "...", "codes": [...], "status": "shipped"}
Функция confirmPOST(Запрос)

    ТелоСтрока = Запрос.ПолучитьТелоКакСтроку();
    Данные = РазобратьТелоJSON(ТелоСтрока);

    ИдЗаказа = Данные.order_id;
    Коды     = Данные.codes;

    // ⚠️ ЗАМЕНИ: пометь эти коды как окончательно выданные (отгруженными)
    // для заказа ИдЗаказа в твоём хранилище.

    Ответ = Новый Структура("ok", Истина);
    Возврат ОтветJSON(Ответ, 200);

КонецФункции

// GET /licenses/stock?product=...
// Возвращает: {"count": N}
Функция stockGET(Запрос)

    Продукт = Запрос.ПараметрыЗапроса.Получить("product");

    // ⚠️ ЗАМЕНИ: посчитай число свободных кодов для Продукт
    Количество = 0;

    Ответ = Новый Структура("count", Количество);
    Возврат ОтветJSON(Ответ, 200);

КонецФункции

// ------------------------------------------------------------
// Вспомогательные функции
// ------------------------------------------------------------

Функция ОтветJSON(Структура, КодСостояния)
    Запись = Новый ЗаписьJSON;
    Запись.УстановитьСтроку();
    ЗаписатьJSON(Запись, Структура);
    Текст = Запись.Закрыть();

    Ответ = Новый HTTPСервисОтвет(КодСостояния);
    Ответ.Заголовки.Вставить("Content-Type", "application/json; charset=utf-8");
    Ответ.УстановитьТелоИзСтроки(Текст, КодировкаТекста.UTF8);
    Возврат Ответ;
КонецФункции

// Имя НЕ "ПрочитатьJSON", иначе функция вызывала бы саму себя
// вместо встроенной глобальной (бесконечная рекурсия).
Функция РазобратьТелоJSON(Стр)
    Чтение = Новый ЧтениеJSON;
    Чтение.УстановитьСтроку(Стр);
    Результат = ПрочитатьJSON(Чтение); // встроенная глобальная 1С
    Чтение.Закрыть();
    Возврат Результат;
КонецФункции
```

> ⚠️ Имя метода-обработчика в свойствах **Метода** должно точно совпадать
> с именем функции в модуле (`getcodeGET`, `confirmPOST`, `stockGET`).

## Шаг 3. Опубликовать сервис на веб-сервере

> ⚠️ База **файловая**, поэтому нужен веб-сервер на этом же компьютере.
> Бот стоит здесь же → в адресе будет `localhost`.

### 3.1. Установить веб-сервер (если ещё не стоит)

Проще всего **Apache 2.4** для Windows (бесплатный):

1. Скачай сборку Apache 2.4 для Windows (например, с apachelounge.com —
   «httpd-2.4.XX-winXX-VS17.zip»).
2. Распакуй в `C:\Apache24`.
3. Открой **командную строку от имени Администратора** и выполни:
   ```
   C:\Apache24\bin\httpd.exe -k install
   C:\Apache24\bin\httpd.exe -k start
   ```
4. Проверь: открой в браузере `http://localhost` → должно показать «It works!».

> Альтернатива — IIS (он встроен в Windows). Если предпочитаешь IIS — скажи,
> дам отдельные шаги. Но с Apache у 1С обычно меньше возни.

### 3.2. Опубликовать базу из Конфигуратора

1. В Конфигураторе: меню **«Администрирование» → «Публикация на веб-сервере…»**.
2. Заполни:
   - **Имя:** `smartika` (это станет частью адреса)
   - **Веб-сервер:** выбери `Apache 2.4` (1С определит автоматически)
   - **Каталог:** оставь предложенный (например `C:\inetpub\...` или
     `C:\Apache24\htdocs\smartika` — 1С подставит сама).
3. Убедись, что стоит галочка **«Публиковать HTTP-сервисы по умолчанию»**
   (или вручную отметь сервис `licenses` в списке на вкладке «HTTP-сервисы»).
4. Нажми **«Опубликовать»**. На вопрос про перезапуск веб-сервера — согласись.

После этого полный адрес сервиса будет такой:

```
http://localhost/smartika/hs/licenses/getcode
                 ↑имя публикации  ↑hs = HTTP-сервисы  ↑корневой URL
```

> Если бот когда-нибудь переедет на другой компьютер — вместо `localhost`
> подставишь IP этого компьютера с 1С.

---

## Шаг 4. Проверить, что сервис отвечает

Открой в браузере прямо на этом компьютере:

```
http://localhost/smartika/hs/licenses/getcode?product=Тест&order_id=123&quantity=2
```

Браузер спросит логин/пароль 1С → введи пользователя 1С из `ONEC_USERNAME`.
Если всё верно — увидишь:

```json
{"codes": ["1C-123-1", "1C-123-2"]}
```

Значит связь работает. 🎉

## Шаг 5. Передать мне данные → я включу бота

Когда Шаг 4 заработает, пришли мне:

- **Адрес базы** — скорее всего `http://localhost/smartika/hs`
- **Логин 1С** (пользователь, у которого есть права на сервис)
- **Пароль 1С**

Я пропишу их в `config.py`, включу боевой код в `services/onec.py`
(сейчас он закомментирован) — и бот начнёт брать реальные коды из 1С.

## Что бот ожидает от 1С (техническая сводка)

| Запрос | Метод | Параметры | Ответ |
|--------|-------|-----------|-------|
| `…/hs/licenses/getcode` | GET | `product`, `order_id`, `quantity` | `{"codes": [...]}` |
| `…/hs/licenses/confirm` | POST | тело JSON `{order_id, codes, status}` | `200 OK` |
| `…/hs/licenses/stock` | GET | `product` | `{"count": N}` |
